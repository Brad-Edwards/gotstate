# 0 Contents

This suite describes the engineering approach of gotstate, a Go library for hierarchical finite state machines.
It holds the engineering chapters only.

Chapters 1 to 12 follow the [arc42](https://arc42.org/overview) structure, licensed under CC BY-SA 4.0.
Diagrams use the [C4 model](https://c4model.com/) levels: context, container and component.
The architecture model is the machine-readable source for the structure.
