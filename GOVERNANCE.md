# Project governance

gotstate is a maintainer-led open source project.
The maintainer decides scope, accepts changes and manages releases.

Pull requests target `dev`.
Reviewed promotion moves `dev` to `main`.
Release Please owns version and changelog state on `main`, and release changes return to `dev` through review.

Design decisions are recorded in [`architecture/designs/`](architecture/designs/).
See [CONTRIBUTING.md](CONTRIBUTING.md) for the working process and [MAINTAINERS.md](MAINTAINERS.md) for current ownership.
