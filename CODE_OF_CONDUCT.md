# Code of conduct

## Expected behavior

Keep project discussions clear, kind and focused on the work.
Good-faith disagreement is welcome.

- Focus criticism on ideas, code, evidence and project goals.
- Give enough context for others to understand a concern.
- Accept that the maintainer can reject work that does not fit the project.
- Do not use personal attacks, harassment or biased language.
- Do not publish private information without permission.

## Scope

This code applies to issues, pull requests, documentation work and the other spaces of the project.

## Report a concern

Report a concern to the maintainer privately.
Use the [private vulnerability reporting](https://github.com/Brad-Edwards/gotstate/security/advisories/new) of this repository, and state that the report is a conduct concern.

The project has one maintainer and no separate enforcement group.
The maintainer can remove comments, close threads, decline work or block a person when necessary.

## Attribution

This policy draws from common open-source conduct policies, including the Contributor Covenant.
