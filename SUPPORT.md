# Get support

gotstate is supported on a best-effort basis.

Anyone can open a GitHub issue for reproducible defects, focused feature requests and documentation problems.
The repository accepts pull requests from vetted authors only.
Use the private route in [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

Include the gotstate version, the Go version and the operating system.
Include the smallest Go code that reproduces the problem, with the expected and the actual behavior.

There is no commercial support channel and no response time commitment.
